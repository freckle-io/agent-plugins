# AI Ark Companies

Read `freckle list build ai-ark companies --help` for command syntax, inline filters, defaults, and preview output. Load this reference for advanced JSON filters.

## Advanced filters

Use `--search-file` for any/all, include/exclude, match-mode, keyword-source, multiple-range, or `advancedAccountFilters` JSON. The file contains the complete AI Ark `filters` object with optional `lookalikeDomains`, `account`, and `advancedAccountFilters`.
